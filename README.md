# Codex Skills

Переиспользуемые навыки для Codex. Навык `ceo-review` находится в ветке [`skills`](https://github.com/ShantaevEB/skills/tree/skills).

## CEO Review

[`ceo-review`](ceo-review/SKILL.md) оценивает идеи, результаты и отчёты с позиции требовательного CEO по пяти критериям:

- Бизнес-ценность и ROI.
- Стратегический фокус.
- Риски и узкие места.
- Масштабируемость.
- Ясность для совета директоров или инвесторов.

Ответ содержит вердикт, жёсткую конструктивную критику, 3–4 вопроса от руководства и конкретные шаги к действию. Навык отделяет подтверждённые факты от предположений и не придумывает недостающие показатели.

## Установка

В Codex отправьте:

```text
$skill-installer установи ceo-review из https://github.com/ShantaevEB/skills/tree/skills/ceo-review
```

Или используйте установщик из локальной установки Codex:

```sh
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo ShantaevEB/skills --ref skills --path ceo-review
```

Если навык с таким именем уже установлен, установщик не перезапишет его. После установки начните новый чат Codex, чтобы навык появился в списке доступных.

## Использование

```text
$ceo-review
Оцени предложение: [описание идеи, цели, затраты, ожидаемый эффект и риски].
```

При вызове без материала навык отвечает: «Режим CEO активирован.»

Инструкции и метаданные навыка находятся в папке `ceo-review/`. Внешние сервисы и дополнительные зависимости для его работы не нужны.
