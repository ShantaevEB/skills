# Codex Skills — описание на русском

[English documentation](README.md)

`skills` — общий каталог переиспользуемых навыков для Codex. Каждый навык хранится в собственной папке с инструкциями, описанием и примерами. Каталог предназначен для разных навыков; CEO Review — первый из них.

Основная документация, инструкции навыков и метаданные интерфейса написаны на английском. Этот файл содержит описание репозитория, установку и руководство по CEO Review на русском языке.

## Установка

Отправьте в Codex:

```text
$skill-installer установи ceo-review из https://github.com/ShantaevEB/skills/tree/main/ceo-review
```

Или используйте установщик из локальной установки Codex:

```sh
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo ShantaevEB/skills --ref main --path ceo-review
```

Установщик не перезаписывает уже существующий навык с тем же именем. Для установки других навыков заменяйте `ceo-review` на нужную папку из каталога.

## CEO Review

Навык действует с позиции опытного, прагматичного и требовательного CEO крупной успешной компании. Он помогает выявить слабые места в материале и подготовиться к обсуждению с руководством, советом директоров или инвесторами.

### Пять критериев

1. **Бизнес-ценность и ROI:** влияние на прибыль, затраты или долю рынка; оправданность вложенных ресурсов. ROI рассчитывается только при достаточных данных.
2. **Стратегический фокус:** соответствие долгосрочным целям и текущим приоритетам компании.
3. **Риски и узкие места:** юридические, репутационные, технические и операционные угрозы, их последствия и способы снижения.
4. **Масштабируемость:** сохранение экономики, качества и управляемости при расширении решения.
5. **Четкость и презентация:** смогут ли совет директоров или инвесторы за две минуты понять проблему, результат и предлагаемое решение.

Критика направлена на решения и аргументы. Навык отделяет факты от предположений, не выдумывает финансовые показатели и учитывает подтверждённые сильные стороны. При неполном контексте даёт предварительную оценку и показывает, какие доказательства нужны.

### Формат ответа

- **Вердикт CEO:** «Одобряю», «Требует доработки» или «Отклонено» с главным аргументом.
- **Жесткая критика:** основные слабые места и слепые зоны в порядке значимости.
- **Вопросы от руководства:** 3–4 острых вопроса перед дальнейшим представлением материала.
- **Шаги к действию:** конкретные исправления с проверяемым результатом.

### Пример вызова

```text
$ceo-review
Проведи критический разбор моего предложения по автоматизации обработки заявок.
Ниже — цель, текущие затраты, бюджет внедрения, ожидаемый эффект и план пилота:
[вставьте материал]
```

Полезно приложить цели компании, исходные показатели, затраты, сроки и критерии успеха. Можно передать и черновую идею: недостающая информация попадёт в вопросы от руководства.

Навык отвечает на языке пользователя, если не запрошен другой язык. При вызове без материала на русском языке ответит: «Режим CEO активирован.»

Внешние сервисы и дополнительные зависимости для работы навыка не нужны.

## Добавление навыков

Создайте отдельную папку с коротким именем в формате `lowercase-with-hyphens`. Обязательный файл — `SKILL.md` с полями `name` и `description` в YAML-заголовке и инструкциями для Codex в основном тексте.

Добавьте английский README с назначением, установкой и примером вызова, затем внесите навык в общий каталог. Русское описание можно добавить в этот файл. Метаданные `agents/`, скрипты, справочные материалы и ресурсы добавляйте по необходимости.
